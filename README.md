# DropOwl website

The AGY project website for DropOwl, published as a static site on GitHub Pages at https://dropowl.me/.

## Site files

- `index.html` — DropOwl landing page
- `privacy.html` — privacy policy
- `terms.html` — website terms
- `delete-account.html` — account deletion instructions
- `css/style.css` — shared site styles
- `js/script.js` — site interactions
- `assets/` — page illustrations, retailer marks, and branding

## GitHub Pages

The repository root is the site root. Keep the existing `CNAME` file set to `dropowl.me`.
